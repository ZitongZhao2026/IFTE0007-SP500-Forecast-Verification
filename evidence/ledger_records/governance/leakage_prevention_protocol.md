# S&P 500 历史回测防数据泄漏协议

版本：`0.1.4-draft`  
状态：**DRAFT / 待人工审核，未批准**  
适用范围：本项目未来经批准的数据、因子、模型、验证、回测与预测。当前只允许 G0 配置，不授权 G1 或任何正式数据处理、模型训练、调参、历史回测与最终预测。  
来源：用户在本会话提供的《S&P 500 历史回测防数据泄漏协议》§1–9；补充参考 `../research/2026-10-28/test_protocol_draft.md`。用户本轮批准的是架构与 G0 配置，不是本协议。两份材料的未决事项见 `decisions_pending.md`。本文件的 SHA-256 由同目录 `protocol_versions.sha256` 记录；变更须产生新版本、新哈希及独立审计，不能覆盖既往批准证据。

## 1. 原则与范围 [P01]

在每个历史预测截止时点 T，预测及其训练只能使用 T 时真实已可获取的信息；防泄漏优先于准确率。仅有实际运行的检查和可追踪证据才可支持“已检查范围内未发现泄漏”，不得声称绝对不存在泄漏。对于无法证实的事项，保留 UNKNOWN，严格实时回测中排除，或经人工批准单独开展明确标注的保守代理假设实验；代理实验不得称为严格 point-in-time 回测。样本减少、无法运行及负面结果均须如实披露。

## 2. 决策时点、目标和方法 [P02]

作业目标为 2026-11-20 S&P 500 Price Index 官方收盘点位，单位指数点；最终信息截止为 2026-11-13 12:00 GMT。历史预测起点模拟历史预测日英国当地时间 12:00，使用时区数据库转换至当时 UTC 和纽约时间，核对 BST/GMT 及英美夏令时错位；依据真实美国交易日历确定目标日，记录休市、早收盘、起点及每期实际交易日数量。目标日休市的具体处理待 D04 决定并核实，不可凭结果删周。

每次 P0 为截止时**正式可得**的最新 S&P 500 Price Index 收盘点位；不得以 SPY、期货、总收益指数或其他资产替代。主要模型目标为 P0 至目标收盘的累计简单收益 `R = P_target / P0 - 1`，点位映射为 `P_target_hat = P0 * (1 + R_hat)`。显式记录收益单位、P0 时间与映射；异常预测处理须事前登记并审批（D09）。

固定六交易日标签只能在已明确与实际预测期限的对应关系后使用；不能机械假定每一历史时点均为六交易日。若采用按 h 区分的模型或限制子样本，应事前确定规则并披露被排除样本，不能按结果挑选。不同 h、重叠标签与相关性应如实报告。

拟定方法仅为 Baseline（预测 P0）、A0（原始因子 + Ridge）、A1（训练内 PCA + Ridge）、A2（原始因子 + 受限回归树）。所有模型须使用一致的历史起点、目标日、可用性规则和最终评价口径。直接点位线性对照仅在预登记预算和人工批准后实施；PLS、MLP、深度学习与额外集成不执行，不得自行增加。旧研究中的 ARIMAX、配置预算与日期分段并非当前批准方案，见 D02–D05。

## 3. 原始数据历史可得性 [P03]

每条记录尽可能保存序列 ID、单位、`observation_date`、`release_timestamp_utc`、`available_timestamp_utc`、`vintage_date` 或版本有效期、`retrieval_timestamp_utc`、来源、值、`data_status`、文件哈希、许可及证据位置。对不同发布时间和修订的具体数值版本分别建档。观察日期、系列级更新时间、首次发布、对应版本可用时间和本次取数时间不能混同；系列更新时间不能自动证明每条历史记录的发布时间。

对预测起点 T 使用的每个具体版本，必须能证明 `available_timestamp_utc <= T`，并证明版本确为当时可取得的值。今天下载的修订宏观历史序列不能直接视为过去已知值。优先查官方历史发布时间、历史 vintage 与原始发布者材料；无证据时不默认可得，标 UNKNOWN 并补证、严格回测中排除，或在人工批准下单列代理实验。仅日期而无时分时，旧草案的下一交易日规则只是候选代理，须经 D06 决定，不能被当作自动通过证明。

**As-of Join 版本选择**：对每个序列、观察期及预测截止 T，只能连接有证据证明在 T 已可获得、且按来源历史版本或有效期能够确定为 T 适用的具体数值版本。观察日期或首次发布日期均不能单独证明某个修订版本的可用性。若同一指标存在多个候选版本，必须在使用前登记并冻结可复现的选择规则，包括来源和版本标识、可得时间与有效期、候选排序及同时间并列处理；规则须与来源证据一致，不能按回测结果选版本。保留匹配依据、所选版本及其时间戳、规则版本与输入快照。无法证明版本在 T 可用或无法依证据唯一确定适用版本时标 UNKNOWN，不得进入严格 point-in-time 回测；不可静默选用当前版本。对训练样本分别以其历史预测起点执行同一原则，对本次预测特征以其 `forecast_cutoff` 执行。

宏观低频值只能在实际发布后按已登记规则前填并保留 staleness，不可回填到发布前；禁止用非交易日插零收益替代真实交易记录。数据许可、来源、频率、缺失、口径、修订及共同可用期须经审计及人工审批。

## 4. 特征与标签 [P04]

每次模型拟合和预测必须分别记录两个带时区、可换算至 UTC 的时间戳：`fit_cutoff` 是该次模型拟合允许使用信息的最后时刻；`forecast_cutoff` 是生成本次预测允许使用信息的最后时刻。须满足 `fit_cutoff <= forecast_cutoff`。两者相等是可能的情形，不得默认总是相等；若沿用预测起点之前已训练完成的模型，须保留实际拟合截止及模型版本，不能把较晚的预测截止冒充拟合截止。每次回测、每一内外层拟合及其相应预测都必须记录和审计这两个时刻；Baseline 无拟合时应说明不适用及其预测截止，不得伪造拟合记录。

所有特征的全部底层输入必须在各自预测起点已经可得。历史收益、波动、利率变化、已发布宏观指标及其他候选因子只有可得性被验证后才能使用。禁止未来交易日真实价格、未来实际 VIX、利率或宏观数据、未发布新闻及事后修订。滚动均值、动量、波动、差分和滞后只允许指向过去的窗口；禁止包含未来数据的居中窗口。保留输入血缘、窗口上下界和最大可得时间，构建后逐起点检查时间戳。

每个样本记录预测起点及截止、P0 日期和可用时刻、目标日期、目标官方收盘及其可用时刻、标签确定时刻。每次拟合时，仅可纳入特征在样本自身历史预测起点已可得、同时不晚于当前 `fit_cutoff`，且标签结果在**实际 `fit_cutoff`** 已可得的样本；本次预测的特征须在 `forecast_cutoff` 已可得。`label_end_at <= fit_cutoff` 单独不能证明结果已发布；还必须检查 `label_available_at <= fit_cutoff`。不得仅删除固定行数或机械套用 `gap`、`purge`、`embargo` 声称无泄漏。标签重叠时核查真实区间、边界和成熟时间，并说明样本相关性；若报告不确定性，方法须预注册。

## 5. 时间顺序验证与预处理 [P05]

当前 Baseline、A0、A1、A2 的正式历史预测实验采用预登记的 walk-forward、expanding 或 rolling 等符合历史信息可得性与标签成熟要求的时间顺序验证；禁止随机打乱时间顺序的交叉验证，禁止用未来样本训练来预测过去验证样本的任何划分。Baseline 无拟合或选参时，相应拟合/选参检查标记 NOT APPLICABLE，仍须遵守预测时点可得性和共同评价规则。逐折分别记录真实 `fit_cutoff` 与 `forecast_cutoff` 并核查前者不晚于后者，按实际拟合截止筛选成熟标签，在训练集内拟合预处理与模型，再对未见验证样本预测并比较真实结果。复用既有模型时记录原始拟合截止及版本。内层选参与外层验证均需各自满足相同时间、版本选择和标签约束；边界及重叠按真实可得时间解释，不能复制其他项目的固定 gap。

缺失值处理、缩放、变量筛选等拟合型步骤必须在对应训练折内部拟合，再应用于后续数据。内层交叉验证前不得使用整个外层训练区间预拟合预处理器而声称内层独立。记录每个拟合器所用行 ID、窗口、时间边界和版本；确保不同模型比较使用事前登记的一致缺失和共同样本规则，披露失败及样本排除。

## 6. PCA、Ridge 和受限树 [P06]

A1 每次拟合的插补、标准化和 PCA 载荷仅使用该次训练折；内层验证的拟合也须重新进行。PCA 主成分数量的选择必须使用训练期内部符合历史信息可得性及标签成熟要求的时间顺序验证；禁止用完整历史先拟合 PCA 或根据最终测试结果决定成分数。记录 PCA 拟合样本起止日期、成分数、解释方差、载荷矩阵、预处理与 PCA 配置、训练窗口和版本。

Ridge 正则化参数、树深度、叶节点最小样本数等只能由训练期内部符合历史信息可得性及标签成熟要求的时间顺序验证选择。当前正式历史预测实验禁止普通随机 K-fold、普通留一交叉验证及其他使用未来样本训练并验证过去样本的划分，不设普通人工审批即可启用的例外。如未来研究需要其他验证方法，必须另行提出研究方案、独立审计并获得人工批准，不得自动纳入本次正式回测。预处理与模型置于适当的训练 Pipeline。树容量、随机种子、候选参数、失败处理和所有尝试须预登记；测试集不得参与超参数、特征或模型选择。

## 7. 冻结与最终测试集 [P07]

首次最终测试前冻结候选因子、数据版本、特征规则、模型列表、超参数范围、验证方法、评价指标和模型选择规则，记录变更、访问历史及哈希。最终测试只能评估冻结方案。测试结果不得用于参数、特征或模型选择；最终模型选择只使用获准的开发验证信息。先前 G5 用语与此存在冲突，保留 D01 供界定具体划分与决策时点；不得以普通人工审批改变测试集用途。

如果查看测试结果后修改方案，保留全部查看和修改记录；原测试区间对该修改重新归为已使用研究数据，不能继续称独立测试。若历史拟留作测试的数据曾参与选择，其独立性为 UNKNOWN 或已污染，不能通过改名恢复。先前建议的日期切分未经批准且独立性未知。

## 8. 评价与完整记录 [P08]

所有方法统一输出目标日指数点位，主指标 `APE = 100 * abs(Forecast - Actual) / Actual`，多个起点为 MAPE；辅助报告点位 MAE、RMSE、相对不变价格 Baseline 的表现、分时期误差和稳定性。保留全体尝试、失败、被排除样本和负面结果；训练 R²、PCA 解释方差、方向准确率及某次漂亮结果不得直接决定最佳模型。训练损失、收益预测和点位评价的差异需披露。

后续应交付 data_dictionary（因子定义、来源、频率及可得性）、forecast_schedule（起点、UTC 截止、P0、目标）、backtest_predictions（模型预测、真实点位、误差）、model_config、leakage_audit、experiment_log 和 README 或等价结构。冻结记录应包含数据许可及可分享样例、代码/依赖版本、配置、随机种子、模型或权重哈希、起点、全部尝试、预测记录、人工决定及复现步骤；按许可限制分享。

## 9. 自动审计与负向测试 [P09]

G3 须实现实际可运行检查；G4 正式回测准入前必须实际运行并通过适用的检查与负向测试，取得独立审计 PASS 和人工批准。至少验证：(1) As-of Join 的具体版本在对应截止前可用且依冻结规则可复现；(2) 每次有拟合的模型预测均记录 `fit_cutoff <= forecast_cutoff`，各训练标签在实际拟合截止时成熟；Baseline 无拟合时依 P04 将拟合检查标记 NOT APPLICABLE 并记录预测截止；(3) 所有预处理器只用对应训练窗口；(4) PCA 不使用验证/测试数据拟合；(5) 内外层验证时间顺序；(6) 超参数选择不引用最终测试结果；(7) 不使用未来真实外生变量；(8) 输入、模型和输出可复现。保留每项证据、代码位置和执行结果；未实现或未运行不得标 PASS。

至少一个故意注入未来信息的负向测试必须证明程序能识别并阻止泄漏。关键检查 FAIL 必须阻止该次预测进入合格回测结果，不得静默跳过；UNKNOWN 不能视为 PASS。还应设计截断未来输入后历史预测不变、标签边界反例、手算收益到点位及基准误差核对。检查的可信度依赖数据来源、完整血缘和实际运行；当前这些代码与测试尚未实现，见 `control_matrix.md`。

## 10. 阶段、职责与审批 [P10]

主 Agent 协调并保留 Auditor 异议；Data Researcher 管数据及因子证据；Model Developer 管模型和验证；Leakage Auditor 独立检查和报告，不修改正式数据、模型或回测结果。三方均使用相同的**经批准**协议版本与哈希，当前草稿未批准。具体 G0–G6、文件所有权、结果状态和人工审批见 `workflow.md`。角色规则不构成沙箱隔离，代码自动检查也不能证明外部时间戳真实或检查范围完整。

数据范围、模型选择、正式回测、重大变更和最终预测必须分别人工批准；审计 FAIL 停止并复审，UNKNOWN 提交人工决定且不能视为通过。先完成资料、潜在泄漏、所需时间戳、架构和未决问题的审计与设计，再依明确审批实施；不得悄悄改日期、因子、评价或数据边界。LLM 已知的公开历史信息不能作为模拟时点实际可得输入或隐性选模依据。
