# S&P 500 预测作业：协作规则

本项目实行主 Agent 与 Data Researcher、Model Developer、Leakage Auditor 三个独立职责。执行任务前必须阅读 `governance/workflow.md` 和 `governance/leakage_prevention_protocol.md`，核对协议版本、SHA-256 和人工批准记录。用户已批准原样冻结的 `0.1.4-draft`，并授权第一批 G1 限定来源核查；具体范围见 `governance/approval_log.jsonl`。禁止因子筛选、PCA 拟合、训练、调参、正式回测及最终预测；后续阶段须分别审批。

- 主 Agent 负责协调、冻结输入、分配文件所有权和记录决定，不能代签审批、修改或覆盖审计异议。
- Data Researcher 负责来源、质量、候选因子和历史发布时间/修订证据；Model Developer 负责经批准的 Baseline、A0、A1、A2；Leakage Auditor 独立检查并报告，禁止修改正式预测数据、模型或回测结果。PLS、MLP 等扩展须另行批准。
- 每个重要阶段均需独立审计。FAIL 阻断并整改复审；UNKNOWN 阻断并提请人工决定，不得视为 PASS；NOT APPLICABLE 必须说明依据。通过检查不等于批准执行下一阶段。
- 角色输出必须包含任务、文件路径、代码位置或明确标注未实现、检查依据、结果、协议版本、输入版本/哈希和限制。保存全部异议、失败、整改和复审记录。
- 同一文件同一时间只允许一个写入负责人。只读研究和对已冻结快照的检查可并行，依赖步骤必须顺序执行；相关输入变化须重新审计。
- 数据范围、模型选择、正式回测、重大变更和最终预测均需人工审批；批准必须绑定具体范围与版本。不得把用户对 G0 架构的原则批准解释为协议批准或后续阶段授权。
- 本文件和角色指令是行为规范，不是系统级权限隔离或自动执行的关卡。不能声称已获得未经验证的技术保障。
