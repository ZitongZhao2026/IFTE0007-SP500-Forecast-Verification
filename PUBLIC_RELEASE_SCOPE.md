# Public release scope and exclusions

This repository publishes screened evidence from the repaired 149-file submission package (SHA-256 db54e7befb8dfa6c7f7699f488df98f3dc31fb7e254b38909bbcd6c2fb4fac4d). The unfiltered ZIP is not published. Every source member has a disposition in [PUBLICATION_MANIFEST.csv](PUBLICATION_MANIFEST.csv). Every original source-ledger entry has a public destination or explicit omission in [PUBLIC_REFERENCE_MAP.csv](PUBLIC_REFERENCE_MAP.csv).

Original final-result JSON, execution code, configuration and existing audit records are preserved byte-for-byte from the existing repository. New summaries and methods are screened separately. The source ledger and a small number of source records are public projections with local path prefixes replaced; their original SHA-256 values are retained in the publication manifest. Three provider metadata projections omit only the personal absolute `raw_path` and add an explicit transformation marker. These are labelled public copies, not fabricated originals. The original frozen files remain unchanged locally. Historical copied documents retain their original as-of statements and project-relative dependency names; the new evidence index and reference map define public navigation.

Excluded: provider downloads; CRSP/WRDS raw or row-level derived financial inputs; final training matrix; per-origin price/prediction/error/feature/coefficient exports whose redistribution suitability is uncertain; private execution manifests; PDF source reports/briefs; local repair administration and residual absolute-path records. Aggregate research results, model-selection summaries, dates/membership hashes, research methods and authentic partial transcripts are retained. No newly constructed or relabelled input sample is supplied; the existing negative-test result is an outcome record, not a synthetic input dataset.

The exact `eva_empirical_evidence` directory was not located; the authentic existing Eva handover keeps its original name. Full original role/tool histories, the initial price-discrepancy discovery dialogue, a separate original 7 November sensitivity execution timestamp and a specifically identified evidence-alignment record remain unavailable. The partial transcript and NOT_FOUND records state their limits. Final-run fitted coefficients, intercept and scaler values were not saved. No reconstruction was performed. Historical Strict PIT and provider first-publication times remain UNKNOWN. The saved pre-cutoff FRED archive does not independently price-confirm the same-date Yahoo P0. G4 was previously examined and is non-independent.

This publication is not an end-to-end retraining environment. Calculation scripts retain original project-relative dependencies; excluded inputs are required for their separately authorised execution. Original 10 November supplementary refit outputs are historical research records, not newly executed results or original 13 November fitted coefficients. No model, backtest, feature reconstruction or coefficient fitting is run for this release.

The published `frozen_training_membership.csv` is a labelled compact column projection: only the repeated full `train_origin_ids` strings are omitted; all cutoff/count and training-ID SHA-256 columns remain unchanged. The original full-file hash is preserved in the publication manifest.
